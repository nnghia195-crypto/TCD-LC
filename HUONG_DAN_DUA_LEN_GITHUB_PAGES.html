Đưa TĐKT Web v1.5.3 lên GitHub Pages

Bản này không cần Python và không cần máy chủ. Chỉ cần tải các file HTML/CSS/JS lên GitHub.

Cách làm dễ nhất

  1. Giải nén file ZIP TĐKT. Bạn sẽ thấy index.html, login.html, thư mục assets, data...
  2. Vào GitHub và tạo một repository mới, ví dụ tdkt-v153. Nên để Public nếu dùng GitHub Free Pages.
  3. Trong repository, bấm Add file → Upload files.
  4. Kéo toàn bộ file và thư mục bên trong gói đã giải nén lên. Quan trọng: index.html phải nằm ngay ở thư mục gốc của repository, không nằm trong một thư mục con.
  5. Bấm Commit changes.
  6. Vào Settings → Pages.
  7. Ở Build and deployment, chọn Source: Deploy from a branch.
  8. Chọn Branch: main và thư mục /(root), rồi bấm Save.
  9. Đợi GitHub xuất bản. Nếu tài khoản là dinhttbx và repo là tdkt-v153, đường dẫn sẽ có dạng https://dinhttbx.github.io/tdkt-v153/.

Sử dụng

Mở đường link GitHub Pages. Tài khoản mặc định: admin / Tdk@2026!.

Quan trọng về dữ liệu: mỗi trình duyệt lưu dữ liệu riêng. Trước khi đổi máy, xóa trình duyệt hoặc xóa dữ liệu website, vào Quản trị → Tải tệp sao lưu JSON. Trên máy khác dùng Khôi phục dữ liệu.

Nếu muốn dùng repository 01-10-2026 đang có

Có thể thay nội dung repository đó bằng bộ file TĐKT, nhưng trang hiện có tại https://dinhttbx.github.io/01-10-2026/ sẽ bị thay thế. An toàn hơn là tạo repo mới tdkt-v153.
